## FFmpeg 9.0.1

`ffmpeg.exe` is built by the scripts in the `ffmpeg` folder of this repository, which
apply `ffmpeg/ddagrab-reconnect.patch` to the release. It is configured with
`--enable-gpl --enable-version3`, so this build is licensed under the GNU GPL
version 3. It statically links:

- x264, GNU GPL version 2 or later: https://code.videolan.org/videolan/x264
- dav1d 1.5.1, BSD 2-clause: https://code.videolan.org/videolan/dav1d
- nv-codec-headers, MIT: https://github.com/FFmpeg/nv-codec-headers
- AMD AMF headers, MIT: https://github.com/GPUOpen-LibrariesAndSDKs/AMF

FFmpeg's source: https://ffmpeg.org/releases/ffmpeg-9.0.1.tar.xz
